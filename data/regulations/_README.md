# Regulations corpus (authored explanatory summaries)

These documents are concise, plain-language explainers written for this demo. They
summarize widely known concepts in agricultural trade and Pakistan import/export
practice (HS codes, SPS/phytosanitary rules, customs duty concepts, import
documentation). They are NOT legal advice and do NOT reproduce any specific
statute, SRO number, or exact duty rate. Where a real figure would be needed, the
text says to consult the current official source (FBR, DPP, Pakistan Single Window).
Every file is an authored summary for retrieval-demo purposes only.
